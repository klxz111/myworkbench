## 智源知识树 → myworkbench「知识树」页面 + 研究定位

数据已勘探完毕：通过 hub.baai.ac.cn/knowledge-tree/graph 页面的 Vue 组件（RelationGraph 实例）可一次性导出全量数据——323 节点（name/category/heat/notionId/size）、791 条边、16 个领域及官方配色，无需登录。树中"持续学习"（热度 4990，机器学习基础域）与"AI 系统与硬件"（热度 17081，一级领域）可直接对应你的研究定位。

### 1. 数据落盘
- 用浏览器从 RelationGraph 组件导出全量 JSON，整理为快照文件 `myworkbench-app/src/data/knowledge-tree.json`：
  `meta{source, extractedAt}` + `categories[{name,color}]×16` + `nodes[{id,name,category,heat,notionId,size}]×323` + `links[[source,target]]×791`
- 静态 import 进页面，无运行时外部依赖；重新抓取方法记入 processing.md

### 2. 实体定位字段（frontmatter 即数据源）
- `fields.ts`：research / profile / opportunity / task 增加数组字段 `knowledge_tree`（值为树节点名称，如 `["持续学习", "AI 系统与硬件"]`）；新增 `list` 字段类型
- `EntityForm`：list 字段渲染为逗号分隔文本输入（join/split），通用表单即可编辑
- `EntityFieldsDisplay` 自动展示（数组 join 已支持）；**不加入 buildRelations**（树节点非实体，不污染关系表）

### 3. `/knowledge` 页面（页面主体）
- `page.tsx` + `KnowledgeClient.tsx` + `_components/KnowledgeGraph.tsx`
- 复用自研 `force-graph.ts` 仿真（323 节点规模无压力，调低斥力/边距参数）；沿用 NetworkGraph 已验证的交互实现：滚轮缩放（光标为中心）、平移、节点拖拽、悬停高亮相邻
- 视觉：按 16 领域官方配色着色，半径 ∝ √热度，一级领域节点加大；侧栏 16 领域热度概览排序条
- 交互：图例点击隔离某领域、搜索定位节点、点击节点 → 详情面板（领域徽章、热度、相邻节点可点击跳转、"在智源查看"外链 notionId→hub.baai.ac.cn/knowledge-tree/<id>）
- **我的定位**：fetch research/profile/opportunity/task 实体读取 `knowledge_tree` 字段，按名称匹配节点 → 高亮描边环 + 图例区"我的方向"清单（含热度、所属领域、同域热度排名）；名称重复时（仅"其他AI领域"）优先匹配一级节点
