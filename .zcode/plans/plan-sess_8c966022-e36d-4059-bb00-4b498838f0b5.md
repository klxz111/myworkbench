## 个人化一轮全做：可定制工作台 + 设置中心 + 个人印记 + 数据画像

### 设计总则
- **偏好全部存 localStorage**（单用户单浏览器，与现有 6 个 mwbench_* 键一致），不动任何 API/数据层，Markdown 仍是唯一数据源。现有键不迁移：`mwbench_theme`、`mwbench_content_editor_mode`、`mwbench_notify_enabled` 继续被原处消费，设置页只负责读写它们。
- 新偏好统一由新文件 `src/lib/prefs.ts` 管理类型化读写（safe JSON + 默认值 + SSR 守卫），键：`mwbench_start_page` / `mwbench_home_layout` ({hidden[], order[]}) / `mwbench_pinned` ([{type,id,title}]，≤8) / `mwbench_identity` ({name, focus, deadline_label, deadline_date})。

### 1. 偏好基建 + 设置中心 /settings（新）
- `src/app/settings/page.tsx`（PageHeader「设置」）+ `SettingsClient.tsx`，纯客户端无新 API。分区：
  - **外观**：主题三态（浅色/深色/跟随系统），直接复用 `src/lib/theme.ts` 的 setTheme
  - **起始页**：主路由下拉 → 点击侧边栏品牌 Logo 时落到该页（Sidebar brand href 改读此偏好）
  - **编辑器**：默认模式（markdown/富文本）→ 现有 ContentEditor 已读该键
  - **通知**：浏览器推送开关（复用 NotificationBell 的授权+键逻辑，必要时抽到 lib）
  - **个人印记**：名字 / 本周焦点 / DDL 名称+日期 表单
  - **首页布局**：「进入编辑模式」跳 `/?edit=1`、「恢复默认布局」、「清空置顶」
  - **数据**：指向 /trash 的导出/导入入口说明
- 入口：Sidebar 底部工具区加齿轮图标（桌面侧边栏 + 移动抽屉）、CommandPalette 页面命令加「设置」。

### 2. 可定制工作台（HomeClient 重构）
- 页面改为 **widget 注册表**：`{key, title, column: 'left'|'right'|'full', defaultHidden, render}`。初始布局＝现状＋新件：左列 已逾期/今日到期/待审核门控；右列 快速捕获/置顶/最近变更/策略/数据管理；全宽 数据画像。
- **编辑模式**：页头「编辑布局」按钮 → 每张卡片出现 [隐藏] 和 [↑][↓]（列内移动；用按钮不用拖拽，避开日历页踩过的拖拽竞态坑），底部「已隐藏」托盘可点 [显示] 恢复，「完成」退出。每次变更即写入 `mwbench_home_layout`，刷新不丢。
- **置顶 widget**：行内搜索框（复用命令面板同一套搜索 API）→ 点结果即置顶；置顶行 = 类型徽章 + 标题链接 + ✕ 取消。空态引导。

### 3. 个人印记（首页顶部问候条）
- 网格上方加一条问候：时段问候（早上好/下午好…）+名字 · 今天日期周几 · 本周焦点一句话 · 距 DDL N 天（过期显示「已过期 N 天」）。
- 未配置时降级为日期 + 「设置名字和本周焦点 →」链接；客户端挂载后再渲染时段/倒计时，避免 hydration 错位。编辑入口只在设置页（行内编辑记为后续）。

### 4. 数据画像（全宽「我的投入」卡）
- 新组件 `src/components/ActivityHeatmap.tsx`（写成一等公民，/stats 以后可直接复用）：84 天活跃热力图（12 周 × 7），hover title 提示日期+次数，明暗两态色阶。
- 卡内三分块：热力图 ｜ 任务完成率（todo/doing/done 计数 + 完成率百分比）｜ 资产计数 chips（entity_counts 前 5，链到对应页）。
- 数据来自已有 `/api/stats`（自带 60s 缓存，零后端改动），仅在该 widget 未被隐藏时才拉取。
