## 本轮自由更新：workspace 实用三件套（全文搜索 / 图片粘贴直传 / 软删回收站）

你正在看 /workspace——上轮把它变成了写作驾驶舱，这轮补上让它"真正顺手"的三个缺口，全部围绕写作场景。

### 1. 跨文件全文搜索
- 新 API `GET /api/workspace/search?q=`：扫描全部 Markdown（跳过 .trash，上限 300 文件），大小写不敏感命中，每文件最多 3 个片段（带行号、±40 字符截断），按命中次数排序，最多返回 30 个文件
- UI：文件浏览器卡片顶部加「文件 | 搜索全文」两个小页签；搜索页签下输入即搜（300ms 防抖），结果=文件名+命中数+片段（关键词高亮 `<mark>`），点击直达编辑页

### 2. 编辑器图片粘贴直传
- MarkdownEditor 的 CodeMirror 加 paste 处理：剪贴板里有图片时拦截，逐张 `POST /api/upload`（白名单 png/jpg/jpeg/gif/webp、≤10MB、服务端生成文件名、进 workspace/attachments/），成功后在光标处插入 `![alt](/api/asset?path=<urlencoded>)`（复用既有资产管线，不新增 API）
- 非图片粘贴不拦截；上传期间状态栏显示「图片上传中...」，失败 alert 不插入

### 3. 删除软删化 + 工作区回收站
- `DELETE /api/workspace/file` 改为移入 `workspace/.trash/<时间戳>-<原相对路径（/→__）>`，不再直接销毁
- 新 API `/api/workspace/trash`：GET 列表（含原路径/丢弃时间/大小）、POST 按 name 恢复（原路径存在则 409）、DELETE 彻底删除（`?name=all` 清空）
- UI：文件浏览器卡片底部「🗑 回收站」折叠区——列表带恢复/彻底删除按钮 + 清空回收站；恢复后文件树自动刷新。.trash 以点开头，现有 tree/overview/search 的遍历天然跳过，不污染统计

### 验证与收尾
tsc → rm -rf .next 重启 → E2E：建测试笔记 → 全文搜索命中与高亮、点击跳转 → 合成剪贴板粘贴图片 → 编辑器插入资产链接且 autosave 落盘 → 删除进回收站/恢复/彻底删除全链路 → 明暗截图 → 清理全部测试数据（含测试附件）→ commit + push（沿用你的常设授权，之后每轮照此办理）。

### 不做（记档）
拖拽文件到编辑器插入链接、回收站自动过期清理、图片压缩。
