### 诊断（已用代码证据证实的问题）
1. **首页无层级**：HomeClient 堆 12 个板块（右列 9 张卡：资本/事件/项目/档案/研究等长尾信息与逾期/待审核平铺），打开看不到"现在该干嘛"
2. **导航混乱**：13 项混排（6 个英文主项 + 7 个中文藏进"更多"下拉）；/board /stats /graph /workspace /trash 完全不在导航里（只能靠命令面板发现）；搜索按钮是死的（`paletteOpen` 状态无人消费，CommandPalette 只听 Ctrl+K）
3. **页壳三种写法**：tasks 页 h1=text-2xl+自带 max-w-7xl（与 layout 的 max-w-7xl 双重嵌套）、decisions/home 页 h1=text-3xl 无嵌套；按钮 focus ring 有无不一
4. **样式漂移**：rounded-lg ×287 vs rounded-xl ×32；卡片内边距 p-4/p-5/p-6 混用；空状态/徽章/按钮每页手写
5. **中英混排残留**：首页 "Updated ..." 英文

### 第一轮范围（约 14 个文件，不改任何 API/数据层，不引入 UI 依赖库）

**1. 设计 token（globals.css @layer components）**
- 组件类：`.card`（bg-white dark:bg-gray-800 rounded-lg border shadow-sm）、`.btn-primary/.btn-secondary/.btn-ghost`（统一 focus ring）、`.badge`（状态/类型两系色沿用现有 TYPE_CONFIG 色）、`.input`、`.page-sub`
- 间距约定写死：页 py-8、卡片 p-5、列表行 p-4、section 间距 space-y-6（替换 p-6×148/p-5×17 的漂移）
- 卡片圆角统一 rounded-lg（32 处 rounded-xl 迁移后归零）

**2. 骨架（layout.tsx 重写 + Sidebar 新建，删 Navigation.tsx）**
- `flex` 双栏：左侧 `<Sidebar>`（`hidden md:flex`，w-56，sticky 全高）+ 右侧 `<main class="flex-1 px-6 lg:px-10 py-8">`（页面级 max-w 包装全部取消，避免双重嵌套）
- Sidebar 分组导航（全中文）：**执行**（今日/任务/日历/看板）、**思考**（决策/证据/信念/研究/实验/知识树）、**资产**（策略/机会/人脉/组织/资本/雷达/个人档案）、**记录**（每日笔记/工作台）、**回顾**（统计/回顾/图谱）——顺带把 /board /stats /graph /trash 提升为一级可见入口；底部：搜索按钮（Ctrl K）、通知铃、主题切换、回收站
- CommandPalette 增加监听 `window` 事件 `mwbench:open-palette`，侧边栏按钮 dispatch——**修活死按钮**
- 移动端：汉堡 → 侧边栏变 off-canvas 抽屉（复用现有 mobileOpen 交互模式）
- 两个高度耦合点适配：workspace 编辑器 `calc(100vh-340px)` 与 graph 页 `calc(100vh-200px)` 按新骨架调整

**3. 统一页壳组件（components/ui.tsx，新文件）**
- `PageHeader`（title + description + actions 右对齐，统一 text-2xl/mt-1）
- `Card`、`EmptyState`（统一"暂无 X"文案容器）、`StatusBadge`/`TypeBadge`
- 提取 `DatedItemList`（逾期/今日/未来条目列表 + 完成推进 + 编辑直达，逻辑来自 TodayClient 的 ItemRow）——今日页与首页共用

**4. 首页改造为「今日工作台」（page.tsx + HomeClient.tsx 重写）**
- 左列（主）：⚠ 已逾期（可完成/编辑）→ 今日到期 → 待审核门控（复用 due-items 数据流）
- 右列：快速捕获（复用今日页逻辑）→ 最近变更（保留时间线）→ 策略卡片一行（≤3）
- **移除**：活跃决策/待审核决策详情/跟进提醒/活跃研究/当前项目/资本/近期事件/下一步行动/数据管理 9 张长尾卡（数据在各自专属页可见）；"Updated" → "更新"
- DataManagement（导出/导入）挂到 /trash 页顶部（数据安全入口聚拢）
- 保留逾期/临期横幅

**5. 核心页迁移（4 页，只换壳不改逻辑）**
- 今日/任务/日历/决策：page.tsx 统一用 PageHeader（删各自 max-w 包装与手写页头），client 内的卡片/按钮/空状态类名替换为 token 类
